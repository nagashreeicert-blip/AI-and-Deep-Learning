# 📘 AI & Deep Learning Exam Pattern

This guide provides a clear overview of the AI & Deep Learning certification exam to help you prepare effectively.

# ✅ 1. Total Questions

120 questions in total

All questions are scored

# ✅ 2. Question Types

Multiple Choice Questions (MCQs)

Scenario-based / problem-solving questions

Some questions may require selecting multiple correct options

# ✅ 3. Exam Duration

150 minutes (2.5 hours)

No scheduled breaks

# ✅ 4. Exam Format

Computer-Based Exam (CBE)

Can be taken:

Online (Proctored)

At authorized test centers

# ✅ 5. Domain-wise Weightage

Domain	Weight
AI Fundamentals	35%
Machine Learning Algorithms	30%
Deep Learning & Neural Networks	25%
Deployment & Model Evaluation	10%

# ✅ 6. Difficulty Level

Moderate to advanced difficulty with scenario-based and coding questions

Tests your understanding of AI concepts, ML algorithms, neural networks, and real-world application

# ✅ 7. Passing Score

The certification body does not disclose an exact passing score

Recommended: aim for 70–75% correct answers

# ✅ 8. Exam Retake Policy

3 attempts allowed within one year of registration approval
