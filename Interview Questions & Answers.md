# 📝 Machine Learning & Deep Learning Interview Questions & Answers

A structured set of interview questions and answers for beginners, intermediate, and advanced professionals preparing for AI, ML, and Deep Learning roles.

# 🟢 Beginner-Level Questions & Answers (10)

Q1: What is Machine Learning (ML)?
A: ML is a subset of AI that enables systems to learn from data and improve performance without explicit programming.

Q2: What is Deep Learning (DL)?
A: DL is a subset of ML that uses neural networks with multiple layers to model complex patterns in data.

Q3: What is supervised learning?
A: A learning approach where models are trained on labeled data to predict outcomes.

Q4: What is unsupervised learning?
A: Learning from unlabeled data to find patterns, such as clustering or dimensionality reduction.

Q5: What is overfitting?
A: When a model performs well on training data but poorly on unseen data.

Q6: What is underfitting?
A: When a model is too simple to capture underlying patterns, leading to poor performance.

Q7: What is a training dataset?
A: A dataset used to train a model to learn patterns.

Q8: What is a test dataset?
A: A dataset used to evaluate a model’s performance on unseen data.

Q9: What is a feature in ML?
A: An individual measurable property or characteristic used as input for a model.

Q10: What is a label?
A: The output variable a model aims to predict in supervised learning.

# 🟡 Intermediate-Level Questions & Answers (10)

Q11: Explain the difference between classification and regression.
A: Classification predicts categorical outcomes; regression predicts continuous values.

Q12: What is a neural network?
A: A computational model inspired by the human brain, consisting of layers of interconnected nodes (neurons).

Q13: What is a loss function?
A: A function that measures the difference between predicted and actual values, guiding model optimization.

Q14: Explain gradient descent.
A: An optimization algorithm that adjusts model parameters to minimize the loss function.

Q15: What is a confusion matrix?
A: A table used to evaluate classification model performance, showing true positives, true negatives, false positives, and false negatives.

Q16: What is regularization?
A: Techniques (L1, L2) used to prevent overfitting by adding penalties to the loss function.

Q17: Explain dropout in neural networks.
A: A technique to randomly ignore neurons during training to improve generalization.

Q18: What is a learning rate?
A: A hyperparameter that controls the step size during model optimization.

Q19: What are activation functions?
A: Functions that introduce non-linearity into neural networks (e.g., ReLU, Sigmoid, Tanh).

Q20: What is feature scaling?
A: Normalizing or standardizing data features to improve model performance.

# 🔴 Advanced-Level Questions & Answers (10)

Q21: Explain Convolutional Neural Networks (CNNs).
A: CNNs are deep networks specialized for processing grid-like data such as images using convolutional layers.

Q22: Explain Recurrent Neural Networks (RNNs).
A: RNNs are networks designed for sequential data, maintaining memory of previous inputs through hidden states.

Q23: What is LSTM?
A: Long Short-Term Memory networks are RNN variants that can capture long-term dependencies in sequences.

Q24: What is overfitting prevention in deep learning?
A: Techniques include dropout, early stopping, regularization, data augmentation, and batch normalization.

Q25: Explain backpropagation.
A: A process of updating neural network weights by propagating the error backward through the network.

Q26: What is transfer learning?
A: Using a pre-trained model on a new, similar task to save time and improve performance.

Q27: Explain reinforcement learning.
A: A learning paradigm where agents learn to make decisions by receiving rewards or penalties from the environment.

Q28: What is hyperparameter tuning?
A: Optimizing parameters that control model training (e.g., learning rate, batch size, number of layers).

Q29: How do you evaluate a regression model?
A: Using metrics like Mean Squared Error (MSE), Root Mean Squared Error (RMSE), Mean Absolute Error (MAE), and R² score.

Q30: How do you handle imbalanced datasets?
A: Techniques include resampling (oversampling/undersampling), synthetic data generation (SMOTE), and using class-weighted loss functions.
